What this is

The experimental lab ships three Groth16/BN254 circuits with a deterministic, fixed-entropy lab setup so that independent machines can rebuild them and compare artifacts. This registry records those independent runs: who ran the suites, on what, and whether their artifact digests match the pinned manifest. It is the working machinery behind the task force ask for verification volunteers — and deliberately the same machinery a future ceremony lane would need (queue, public log, per-seat attestation), built where nothing secret exists yet.

  • Acceptance is decided by verify-run.mjs against artifacts.manifest.json — named verdicts, never adjectives. Wall-clock timings are informative only and never enter the decision.
  • The compiled circuit (r1cs, wasm, constraint counts) must match byte-exactly — that is deterministic by construction. The setup chain (ptau, zkeys, vkey) is machine-local: snarkjs mixes its own randomness into every contribution regardless of the fixed entropy string (established empirically, 2026-08-11, by same-machine rebuild). Setup digests are recorded as advisory; the proving-system claim comes from the volunteer's own suites running green — real proofs verified against their own build.
  • Submissions carry digests and a run record — never artifacts (a full rebuild is ~92 MB; a report is a few KB).
