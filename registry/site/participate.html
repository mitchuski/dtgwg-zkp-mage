Run it yourself

Prerequisites: Node ≥ 20, the circom 2.x compiler on PATH, and Python 3 for the cross-language consumer. Everything else pins from the committed lockfile.

git clone https://github.com/mitchuski/dtgwg-zkp-mage
cd dtgwg-zkp-mage/runtimes/circom-gadget
npm install

node setup.mjs          && node test.mjs            # 10/10
node setup-dual.mjs     && node test-dual.mjs       # 7/7
node setup-guardian.mjs && node test-guardian.mjs   # 8/8

node report.mjs                                     # digests + run record
node verify-run.mjs build/report.*.json             # verdict vs the manifest

Or let the orchestrator drive the whole flow and print a paste-ready submission (seat ids are the task force admission list — ask in the upstream Discord channel or an issue):

cd ../ceremony-orchestrator
node orchestrate.mjs <your-seat-id>
  • File the printed submission via the verification-run issue template.
  • Timings vary by machine and are informative. The circuit digests (r1cs/wasm) are the byte-exact claim; your setup-chain digests will legitimately differ (contribution randomness) and are recorded as advisory.
  • A mismatch is a contribution: a reproducible divergence on a required artifact is exactly the kind of finding the position protocol wants (position: refute, with your report attached).
