## 1. B2 — Issuer–Verifier Collusion Target for EPP (you lead, 15 min)

The question as v0.3 §3 puts it: *must a context boundary survive the issuer and the verifier acting together?*

**Position the lab evidence supports: achievable for the proof artefact, not for the enrolment root — so the target must be stated per-horizon (drafting rule 2).**

- **What collusion gets from the artefact: nothing new.** Nullifier = `Poseidon(TAG, secret, context)`; the issuer never sees `secret` (blinded commitment at enrolment), the verifier sees only the scope-bound pseudonym. Joining their views links what each already had — the context descriptor digest is public by design. Backed by: `canonical/` (§6.2 descriptor = the context IS a governed, auditable object) + circuit Z-tests (cross-context unlinkability holds at the constraint level).
- **What collusion gets from the enrolment root: the population.** The deduplicating enrolment is the correlatable artefact (v0.3 §2 says this plainly). No construction fixes this; it's the governance layer's clock. This is drafting rule 2 doing its work: *artefact horizon ≠ root horizon.*
- **The real deployment lever: issuer independence.** X8 `multi-issuer/` makes it decidable — the independence register with declared dependency classes; **correlated issuers collapse to one component and the group ε = max** (collapse always weakens the bound, executable in the suite). An issuer–verifier collusion target for EPP is only meaningful if the issuer set's dependency classes are declared in the registry. Deployment implication: **the collusion target becomes a registry field, not a spec adjective.**
- **Watch the side channels.** X4 `quiet-presentation/` — even if the crypto holds, status/error/shape/retry surfaces leak to the §19 observers. A collusion target that ignores the presentation surface is a mood (rule 1).
- Honest boundary: **contested-recovery is the known observably-identical case** (honest vs attacker) — retryAmbiguous in register v2. If EPP promises collusion-survival, recovery flows are where it's hardest.

Suggested framing sentence: *"Yes for the show, no for the enrolment root, and only as strong as declared issuer independence — so the EPP profile should carry the target as (adversary, horizon, ε-register) triple, not as a yes/no."*

## 4. Root paper 2026/333 — plain-language walkthrough (you lead, time permitting)

Three-sentence version for new members:

> *Two kinds of credentials build the graph: a **PHC** — an authority attests "this is a real, distinct human" once — and **VRCs** — peers attest "we have a relationship" many times. ZK proofs let you show things about those credentials (I'm a unique human in this context; k independent parties vouch for me) without showing the credentials themselves. The paper's core theorem is the one our v0.3 is built on: you cannot have full unlinkability AND Sybil resistance — the same enrolment that makes you provably unique is what makes you correlatable — so every real system picks a point on that trade curve, and picking it is a governance decision, not a math one.*

Mapping to our vocabulary: PHC ↔ personhood anchor / rt01 enrolment; VRC ↔ rt07 edges; unlinkability-across-contexts ↔ our context descriptor + scoped nullifiers; the impossibility ↔ v0.3 §2 trade curve (three claims = three points). Note for the fan-out item: **Hart Montgomery is an author** — the Berkeley engagement and the normative reference are the same thread.
